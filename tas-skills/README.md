# TAS Skills

This directory contains skills that help Agent Hosts set up and connect to the Trustless Agent Substrate (TAS).

## Overview

TAS Skills are designed for Agent Hosts (Claude Code, OpenClaw, Hermes, Codex, etc.) to:
- Register new ERC-8004 Agent identities
- Configure and establish MCP connections to TAS
- Initialize authentication and signing capabilities

## Available Skills

### setup/
Core setup and connection skills for TAS infrastructure.

- **register-agent.md** - Guide for registering a new ERC-8004 Agent identity
- **connect-tas.md** - Guide for connecting an Agent to TAS via MCP

## Usage

These skills are intended to be invoked by Agent Hosts during initial setup or when connecting a new Agent to the TAS network.
