## Task 1 notes

- Standard `npm run typecheck` checks both production sources and `tools/**/*.ts`.
- Viem source integrity is required as a canonical 64-byte SHA-512 SRI value for both A2 Manifest profiles.
- Runtime dependency arrays are canonical profile-specific sequences: Public uses `chain_client`; Wallet uses `chain_client, account` and requires `evm_private_key`.
- Canonical JSON validation clones into inert plain containers before invoking the canonicalizer, so accepted aliases are serialized independently and untrusted getters or `toJSON` functions are never invoked.
- Only validated primitives are passed to `canonicalize`; container ordering and serialization use inert no-prototype storage without mutable Array-prototype methods.
- The pre-Zod guard requires every structured field and array entry to be an own enumerable data property, rejects Proxies and unknown own keys, and fails closed before Zod when Object/Array prototype pollution could affect projection.
- Embedded input/output Schemas are recursively validated and returned as detached null-prototype JSON clones. Prototype-named extension data remains inert; callable/accessor `toJSON`, functions, symbols, bigint, non-finite numbers, Proxies, cycles, and non-enumerable or non-plain values fail closed.
- The shared clone allows at most 10,000 expanded nodes, counting every repeated DAG expansion. Canonical serialization allows at most 1 MiB of UTF-8 and checks each token against the remaining budget before append.
